# I2TC Solutions FZ-LLC

Static website for I2TC Solutions FZ-LLC — a UAE-based technology company.

## Structure

- `index.html` — Home page
- `products.html` — Products page
- `contact.html` — Contact page
- `css/style.css` — All styles
- `js/main.js` — Mobile menu toggle
- `favicon.svg` — Favicon

## Deployment

Upload all files to any static host (GitHub Pages, Netlify, Vercel, or any web server). No build step required.
